# План работ: Project CarSort

Черновик на утверждение. Источник правды по механикам — `GDD.md`, открытые вопросы — `GDD_CHECKLIST.md`.

## Принципы
- Каждый этап заканчивается WebGL-сборкой, проверенной в браузере, а не только в редакторе. Целевая платформа проверяется с первого этапа, не с последнего.
- Всё, что зависит от контента (цены, количество моделей), живёт в ScriptableObject и балансируется в конце.
- Greybox сначала: кубы вместо машинок, один стеллаж, три модели. Арт подключается, когда ядро играется.
- Два решения принимаются до первой модели и не пересматриваются: один атлас + один материал на все машинки; сфера активации физики.
