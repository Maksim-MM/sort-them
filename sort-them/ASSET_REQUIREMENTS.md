# Техтребования к боевым ассетам машинок

Зачем: в зале одновременно лежит 4000 машинок (как в референсе), рисуются они через GPU instancing одним материалом. Ассет, не подходящий под эти условия, ломает инстансинг и возвращает 4000 draw call'ов.

## Геометрия
- Одна модель = один меш, один сабмеш, без дочерних объектов (колёса, стёкла, кузов — в одном меше).
- Бюджет: 300–600 треугольников на машинку, жёсткий потолок 800. Текущие болванки: 688 треугольников, 800 вершин, этот уровень уже тяжёл для телефона.
- Без скиннинга, анимаций, blend shapes. Без LOD-групп (при необходимости упрощённые меши сделаем сами).
- Пивот в геометрическом центре модели (центр коллайдера), не в основании. Ось вперёд +Z, верх +Y, масштаб 1 юнит = 1 м, в импорте без дополнительного масштаба.
- Размеры как у текущих болванок: ширина 0,13–0,34 м, высота 0,09–0,32 м, длина 0,26–0,42 м. Полки рассчитаны на эти габариты.
- Нормали сглажены там, где нужно, без дублирования вершин ради жёстких граней сверх необходимого.

## Материал и текстуры
- Один общий материал на все 100 моделей. Два допустимых варианта, выбрать один для всего набора:
  1. Цвет в вершинах (как сейчас), без текстур. Самый дешёвый для телефона.
  2. Один атлас на все машинки: 2048×2048 максимум, без альфы, без прозрачности, без карт нормалей и metallic/smoothness. UV в пределах атласа, без тайлинга.
- Никаких отдельных материалов на стекло, фары, колёса. Пер-модельные цвета только через вершины или атлас.
- Никаких прозрачных частей. Никакого emission.

## Коллайдер и физика
- Коллайдер BoxCollider по габаритам модели, ставится нашим генератором префабов по bounds меша. Mesh collider запрещён.
- Rigidbody и логика добавляются нашим кодом, в FBX ничего физического не нужно.

## Файлы и имена
- Формат FBX (binary), Y-up, один файл на модель.
- Имя: `car_<категория>_<nn>.fbx`, латиница, без пробелов и кириллицы (требование Яндекс Игр к файлам сборки распространяется на исходники).
- Категории и число моделей: по каталогу `CarCatalog.asset` (10 категорий × 10 моделей).
- Текстура атласа: `cars_atlas.png`, PNG без альфы.

## Что проверяем при приёмке
- Треугольники и вершины в статистике импорта Unity.
- Один материал после импорта, префаб собирается генератором без ручных правок.
- Куча из 4000 машинок рисуется инстансингом: в профайлере Instanced Batches ~100–200, а не 4000 батчей.

## Остальные объекты зала (стеллажи, терминал, автомат, касса, канистры, бомба)
- Отдельные требования не нужны: объектов десятки, не тысячи. Разумный бюджет 1–3 тысячи треугольников на стеллаж, обычный URP Lit, можно с текстурами.
