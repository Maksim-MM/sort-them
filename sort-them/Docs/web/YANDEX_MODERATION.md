## 1. Сроки и процесс ([MOD])

| Что | Срок / правило |

## 4. Чекер (Nioris/yandex-games-debug-checker, v1.1.0)

Что это: один файл `debugcheck.js`, без зависимостей, без сети. Статически читает `index.html` и локальные JS/CSS, в рантайме следит за SDK-вызовами, таймингами, рекламой, языком, поведением страницы. 93 проверки: REQ (привязка к пункту требований), REC (к рекомендациям), HEURISTIC (эвристика, не вердикт). Статусы: PASS / FAIL (редко, только прямые нарушения) / WARN (риск) / NOT VERIFIED (нет доказательств, в score не идёт) / N/A.

Подключение к нашей сборке (только тестовая сборка):
1. Скачать `debugcheck.js` из репозитория, положить рядом с `index.html` билда (или в WebGL-шаблон тестовой конфигурации).
2. В `index.html` в `<head>`: сначала SDK, потом чекер, потом скрипты игры:
   `<script src="/sdk.js"></script>` → `<script src="debugcheck.js"></script>` → loader Unity.
   Без SDK (до подключения плагина) большинство REQ по SDK будут FAIL/NV — это ожидаемо.
3. Открыть панель: `Ctrl+Shift+2` три раза подряд, или в DevTools `YGDebugChecker.open()`; перепроверка — `YGDebugChecker.refresh()`. Если Unity перехватывает клавиатуру и хоткей не срабатывает — открывать из DevTools (поведение с Unity **не проверено**).
4. Опционально для сложного выбора языка: `window.YGDebugCheckerConfig = { supportedLanguages: ['ru','en'], resolveLanguage: fn }` — нужно только чекеру.

Что для Unity WebGL чекер реально даст ([CHK] limitations: логика в WASM недоступна статике):
- Runtime: SDK загружен и инициализирован, `environment.i18n.lang` прочитан, язык до Game Ready, тайминг Game Ready (не слишком поздно), ошибки в консоли (6.4), нет скролла документа/swipe-to-refresh (1.10.2), реально заблокировано контекстное меню (1.6.2.7), переполнение viewport, канвас на весь экран, контекст показа interstitial (4.4), RV только после жеста пользователя (4.5).
- Static по `index.html`/CSS: тег SDK, `YaGames.init()`, `overflow:hidden`, `overscroll-behavior`, `user-select`, `touch-action`, viewport meta, отсутствие S3-URL, alert/eval/document.write.

Что останется NOT VERIFIED / недостоверно для Unity: всё, что внутри WASM — пауза звука и игры при рекламе (4.7), `visibilitychange`/пауза звука (1.3) в C#-коде, сохранение перед рекламой (4.2), раскладка/горячие клавиши (1.6.2.4, 1.6.2.6), тексты на канвасе (перевод, мат), «выглядит завершённой», облачные сохранения/лидерборды/инапы в C#. Плюс в принципе вне чекера: размер и имена в архиве, настройки черновика, промо, round-trip сохранений, контент.

**Перед релизом удалить** и `<script src="debugcheck.js">`, и сам файл из билда ([CHK]). Лучше держать отдельный тестовый WebGL-шаблон, чтобы чекер физически не попадал в релизный.

Официальная debug-панель Яндекса: `?debug-mode=16` в конце URL черновика; показывает индикаторы Game Ready, Gameplay, язык, `IT/IF`; кнопка SDK mocks → Choose Game Lang для проверки языков (`…/requirements/1/19`, `…/requirements/2/14`, [YG2] FAQ).

## 5. Как это ложится на PluginYG2 ([YG2])

- Game Ready: `YG2.GameReadyAPI()`; по умолчанию Auto GRA включён и вызывает его после загрузки. Если после загрузки ещё грузим сцену/данные — выключить Auto GRA и звать вручную.
- Gameplay: `YG2.GameplayStart()/GameplayStop()` — необязательны; если хоть раз вызван Start, плагин сам делает Stop/Start вокруг рекламы и пауз, восстанавливая прежнее состояние. `YG2.isGameplaying`.
- Пауза: Basic Settings → Auto Pause Game (вкл. по умолчанию) при рекламе, окнах авторизации/покупок, потере фокуса, смене вкладки: `Time.timeScale`, `AudioListener.pause`, `Cursor.visible`, `Cursor.lockState`, отключение EventSystem. Рекомендуют менять эти параметры только через `PauseGameYG.SetState(timeScale, audioPause, cursorEnable)` (или вариант с `cursorVisible, cursorLockState`) — иначе при многократной смене курсора во время рекламы курсор может пропасть после неё (заявлено как неустранимое ограничение). События: `YG2.onPauseGame(bool)`, `YG2.isPauseGame`; фокус: `onShowWindowGame/onHideWindowGame/onFocusWindowGame`, `isFocusWindowGame`. В редакторе: General Simulation → Pause On Focus Game.
- Язык: модуль Localization; `YG2.lang` (коды `ru`, `en`), Set Language Mod = «при каждом запуске» (так требует ЯИ), `YG2.onCorrectLang` для маппинга неподдержанных языков в `en`, `YG2.SwitchLanguage()` + `onSwitchLang` для ручного выбора. В редакторе: General Simulation → Language. FAQ на замечание по 2.14 предлагает модули Localization + Auto Translate Langs — у нас Unity Localization, значит нужен свой мост `YG2.lang` → `LocalizationSettings.SelectedLocale` (реализация — наша задача, в [YG2] готового моста для Unity Localization не нашёл).
- Звук в фоне: FAQ — снять Run In Background. Системный плеер в шторке: Load Type = Decompress On Load.

## 6. Ручной чеклист перед отправкой

Из [CHK] `docs/manual-checklist.md` и требований:
- [ ] Черновик с `?debug-mode=16`: `IT`, Game Ready зелёный ровно в момент доступности меню — и при автоскрытии лоадера Яндекса, и при ручном скрытии кликом; холодная загрузка; ≤ 90 с (1.19.2).
- [ ] Каждый язык из «Игра переведена на» через SDK mocks: весь UI и тексты на канвасе переведены, язык выбран на старте (2.14, 8.2.3).
- [ ] Прогресс после значимого действия → F5 → то же состояние; на телефоне — после поворота; без авторизации (1.9).
- [ ] Если инапы: каталог, валюта/иконка из SDK, выдача, consume, сохранение после F5, облако (1.13).
- [ ] RV: только по явному выбору, награда выдаётся один раз (4.5).
- [ ] Interstitial только в логических паузах; по действию — показ сразу (≤ 2 с) (4.4).
- [ ] Звук и геймплей на паузе во всех колбэках fullscreen-рекламы и при сворачивании/смене вкладки; после возврата всё работает, курсор корректен (1.3, 4.7, 1.14).
- [ ] Все браузеры окружения; ПК и мобильные, обе ориентации, если не зафиксирована в консоли (1.20, 1.10).
- [ ] Ресайз окна: -20% по осям, масштаб 80–125%, широкие мониторы; нет скроллбара, обрезки, наложений; соотношение ≤ 2:1 (1.10, 1.6.2.2).
- [ ] Лонгтап/ПКМ по канвасу — без выделения и контекстного меню (1.6.1.8, 1.6.2.7).
- [ ] Системный медиаплеер не появляется ни на ПК, ни в шторке Android (1.6.1.6).
- [ ] Управление на русской раскладке; нет действий на системных сочетаниях (1.6.2.4, 1.6.2.6).
- [ ] Консоль DevTools чистая на старте, в игре, при рекламе, повороте, сохранении, повторных сессиях (6.4, 1.14).
- [ ] Архив: распакованный размер ≤ 100 МБ, `index.html` в корне, имена латиницей без пробелов (1.21, 1.22) — чекер это не проверяет.
- [ ] Нет debug-UI, dev-консолей, `debugcheck.js` (1.15).
- [ ] Промо, иконка, обложка, скриншоты, описание, «Как играть», возрастной рейтинг, облачная галка, комментарий о монетизации (5.x, 8.x, 1.11, 1.12).

## 7. Известные риски для Sort Them

1. **Run In Background включён** (проект: `runInBackground: 1`) → звук в фоновой вкладке → нарушение 1.3. До плагина: выключить и/или ставить `AudioListener.pause` по потере фокуса.
2. **Pointer lock / курсор.** FPS-камера держит курсор залоченным. При рекламе, окнах покупок/авторизации, потере фокуса курсор должен освобождаться, после — корректно возвращаться; иначе тупик или «мёртвый» ввод (1.14, 4.7; поведение описано в [YG2] pause-game). Уже сейчас сводить управление курсором/timeScale/звуком в одну точку, чтобы потом заменить её на `PauseGameYG.SetState`. Браузер сам снимает pointer lock по Esc (поведение браузера, не из [REQ]) — игра должна корректно показать паузу/меню, а не остаться без курсора.
3. **Горячие клавиши (1.6.2.6).** Ctrl в сочетании с WASD (Ctrl+W закрывает вкладку), Ctrl+R, Ctrl+T, Tab-сочетания. Присед на Ctrl — кандидат на замену (C / Left Ctrl → проверить, что не бьётся с системными). Список «запрещённых» в [REQ] не приведён — решать по здравому смыслу.
4. **Раскладка (1.6.2.4).** Биндинги по физическим клавишам; проверить на ru-раскладке и на macOS.
5. **Мобильные жесты (1.6.1.5).** FPS с pointer lock на телефоне не работает — нужен полноценный touch-контрол для движения, обзора и взятия/броска машинки, иначе мобильные не заявлять.
6. **Ошибки в консоли (6.4, 1.14).** Проект: `webGLExceptionSupport: 1`; любые исключения/404 на старте видны модерации. Технический текст/ошибки на экране — прямое нарушение 1.14.
7. **Размер (1.21).** 100 МБ распакованно — считаются все файлы билда (`.data`, `.wasm`, `.framework.js`, StreamingAssets). Сжатие Brotli уменьшает архив, но что именно считается «распакованным» для сжатых `.br` — **не проверено**; безопаснее держать и сжатый билд заметно ниже 100 МБ и мониторить `.data`.
8. **Язык (2.14).** Сейчас locale Unity Localization, вероятно, выбирается по системному языку/сохранённой настройке. После плагина источник — только SDK при каждом запуске; ручной выбор допустим, но сохранённый ручной выбор не должен ломать автоопределение на старте (формулировка [YG2]: «при каждом запуске» — требование ЯИ).
9. **Сохранения (1.9, 1.13.3).** PlayerPrefs допустимы только без инапов. Раз покупки планируются — облако обязательно, и сохранение должно быть инкрементальным (после действия), а не только в `OnApplicationQuit` (в вебе он ненадёжен — общий факт Unity WebGL, не из [REQ]).
10. **WebGL-шаблон (1.6.1.1, 1.6.1.7, 1.6.2.1, 1.10.2).** Проект: `webGLTemplate: APPLICATION:Default` — фиксированный канвас с футером. Нужен полноэкранный шаблон (плагин ставит свой) с `overflow:hidden`, блоком контекстного меню и без WebGL-уведомлений.
11. **Game Ready (1.19.2).** Если после загрузки есть Title-сцена с догрузкой — Auto GRA сработает раньше, чем меню станет интерактивным → выключить Auto GRA.
12. **Кнопка «Выход» (6.7)** и прочие десктопные/консольные элементы UI (глифы геймпада) — в вебе без пользы; рекомендация, не блокер.
13. **Бренды машинок (3.5).** Реальные марки/логотипы — риск по авторским правам.
