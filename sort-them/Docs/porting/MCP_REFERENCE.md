## Unity MCP — справочник

Доступен только когда Unity Editor открыт. Все пути — относительно `Assets/`.

Версия пакета: unity-mcp 10.0.0 (CoplayDev, `#main`). Справка актуальна на 2026-07-01.

### ⚠️ Протокол старта: закрепить инстанс ДО первого вызова

У разработчика часто открыто **несколько окон Unity одновременно** (разные проекты). Без закреплённого инстанса stdio-вызовы маршрутизируются **недетерминированно** — часть tool-call'ов одной сессии может уйти в чужой проект. Прецедент: `get_build_settings` ушёл в чужое окно, и в порт-доки попал чужой конфиг сцен (ложный «сломанный Build Settings»).

**Правило — перед ПЕРВЫМ Unity-MCP-вызовом сессии, всегда:**
1. Прочитать ресурс `mcpforunity://instances` (список `Name@hash` активных редакторов).
2. Если инстансов >1 (или список не читается) — `set_active_instance` с **`Name@hash` своего проекта** и только потом работать. Если инстанс ровно один — убедиться, что это нужный проект (Name = имя папки проекта).
3. **По порту НЕ закреплять:** порт нестабилен даже у одного проекта — после domain reload сервер мигрирует (наблюдалось 6401→6400→6401 в одной сессии). `Name@hash` стабилен.
4. Первым содержательным вызовом сверить, что попал куда надо: `project_info`/путь проекта должен совпадать с рабочей папкой. Признаки чужого инстанса: незнакомые имена ассетов/сцен, «сцена не найдена» при живом файле на диске.

| Инструмент | Что делает |
|---|---|
| `manage_scene` | Иерархия сцены, загрузка/сохранение сцен |
| `find_gameobjects` | Поиск объектов по имени, тегу, компоненту |
| `manage_gameobject` | Создание/изменение/удаление GameObject |
| `manage_components` | Добавление и настройка компонентов |
| `create_script` | Создание C# скрипта (авто-компиляция) |
| `script_apply_edits` | Редактирование существующего скрипта |
| `validate_script` | Проверка скрипта без применения |
| `read_console` | Чтение ошибок и логов консоли Unity |
| `manage_asset` | Работа с ассетами проекта |
| `manage_prefabs` | Создание и редактирование префабов |
| `manage_material` | Создание и настройка материалов |
| `manage_camera` | Управление камерой, скриншоты сцены |
| `manage_graphics` | URP настройки, Volume, освещение, запечка |
| `manage_packages` | Установка и управление пакетами |
| `manage_editor` | Play mode, undo/redo, меню редактора |
| `batch_execute` | Пакетное выполнение нескольких операций (до 25) |
| `unity_reflect` | Поиск по C# API через reflection |
| `unity_docs` | Документация Unity с docs.unity3d.com |
| `set_active_instance` | Пин активного Unity-инстанса (Name@hash) при нескольких открытых редакторах |
| `manage_ui` | Работа с UI Toolkit / Canvas-элементами |
| `manage_build` | Настройка и запуск сборок (профили, платформы) — ключевое для консольного порта |
| `manage_physics` | Настройки физики (важно: игра построена на Rigidbody-предметах) |
| `apply_text_edits` | Точечное редактирование скрипта по диапазонам строк |
| `find_in_file` | Поиск по содержимому файла (навигация перед правкой) |
| `manage_script` | Операции над C#-скриптом целиком (создание/чтение/удаление) |
| `execute_code` | Выполнение произвольного C# в редакторе (быстрые проверки/reflection) |
| `run_tests` | Запуск тестов (EditMode/PlayMode) |

Точное редактирование скриптов: связка `apply_text_edits` + `find_in_file` — более аккуратная альтернатива `script_apply_edits` для мелких правок.
