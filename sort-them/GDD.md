# Game Design Document (GDD): Project CarSort

## 1. High Concept & Core Loop
* **Жанр:** 3D-симулятор сортировки от первого лица / Cozy Cleanup / Incremental.
* **Сеттинг:** Склад-магазин игрушечных машинок в стиле Low-Poly.
* **Аудио-визуальный стиль:** Мягкая палитра, расслабляющий лоу-фай эмбиент, тактильные щелчки пластика/металла при установке деталей.
* **Core Loop:**
  $$\text{Сбор из кучи} \longrightarrow \text{Сортировка по полкам} \longrightarrow \text{Заработок валюты} \longrightarrow \text{Прокачка в терминале} \longrightarrow \text{100\% порядок}$$

---

## 2. Архитектура данных (Data-Driven)

Система строится без хардкода наименований через ScriptableObjects / JSON-конфиги.

### CategoryData
* `string CategoryID` — уникальный ID категории (`cat_muscle`, `cat_supercars`, `cat_emergency`).
* `string DisplayName` — отображаемое название («Маслкары», «Спецтехника»).
* `Color CategoryColor` — цвет индикатора на стеллаже.

### CarItemData
* `string CarID` — уникальный ID модели (`car_mustang_red`).
* `string DisplayName` — название модели («Красный маслкар '69»).
* `string CategoryID` — привязка к родительской категории.
* `GameObject Prefab` — Low-poly префаб с Rigidbody, Collider и звуковым триггером.
* `int UnitPrice` — базовая выплата за корректную установку ($1–$5).
* `int ShelfBonusPrice` — бонус за полное закрытие всей полки ($20–$50).

## 3. Механика полок и слотов (Shelf System)

### Параметры полки (ShelfController)
* **Вместимость:** Ровно 10 слотов (`SlotPoint[10]`) с точками привязки (`Transform`).
* **Динамическая привязка:**
  * **Empty:** Полка пуста, не закреплена за категорией/моделью.
  * **Assigned:** Первая установленная машинка задает требуемый `TargetCarID` (или `CategoryID`).
  * **Reset:** Если все машинки сняты с полки, она возвращается в статус `Empty`.
* **Манипуляция:** Игрок может свободно забрать любую машинку обратно в инвентарь без штрафов.

### Валидация и индикация ценника (Price Tag)
У каждой полки есть интерактивная табличка/дисплей:
* **Белый цвет (Valid):** Машинка соответствует правилу полки. Начисляется выплата `UnitPrice`.
* **Красный цвет (Invalid):** Машинка установлена ошибочно (другая модель/категория). Выплата не начисляется.
* **Триггер завершения (Completion):** При заполнении 10/10 валидных слотов:
  1. Табличка подсвечивается зеленым/золотым цветом.
  2. Проигрывается звуковой джингл.
  3. На баланс начисляется `ShelfBonusPrice`.

## 4. Контроллер игрока и манипуляция объектами

* **Камера:** First-Person (вид от первого лица).
* **Стек инвентаря:**
  * Базовая емкость: 5 слотов (`0/5`).
  * Скролл колесом мыши переключает активный предмет в руках.
* **Взаимодействие:**
  * **ЛКМ (клик):** Положить активную машинку в подсвеченный слот полки (Raycast).
  * **ЛКМ (удержание):** Зарядить бросок машинки по физической дуге.
  * **ПКМ:** Забрать машинку с полки или поднять с пола.
* **Система возврата (Unstuck):** Кнопка в меню или триггер, респаунящий провалившиеся под геометрию машинки в центр зала.

## 5. Дерево улучшений (Терминал Upgrades)

| Улучшение | Стоимость | Тип | Механика |
| :--- | :--- | :--- | :--- |
| **Больший инвентарь** | $30 (рост за лвл) | Накопительный | Увеличивает лимит переноски (+1, +2, +5...). |
| **Большая дальность** | $20 | Пассивный | Увеличивает дистанцию Raycast для взаимодействия. |
| **Открыть спринт** | $50 | Бинарный | Разблокирует быстрый бег на `Left Shift`. |
| **Открыть присед** | $30 | Бинарный | Разблокирует присед на `Left Ctrl` для сбора под полками. |
| **Более сильный бросок** | $20 | Пассивный | Увеличивает начальный импульс силы броска (`AddForce`). |
| **Авторасстановка при броске** | $100 | Пассивный | При попадании брошенной машинки в коллайдер нужной полки модель плавно магнитится (`Lerp`) в слот. |
| **Подсветка парных полок** | $100 | Активный | При машинке в руках подсвечивает контур нужного стеллажа. |
| **Подсветка дубликатов** | $100 | Активный | Подсвечивает силуэты аналогичных машинок в куче. |
| **Автосбор совпадений** | $150 | Активный (КД) | Автоматически затягивает в инвентарь одинаковые машинки из радиуса вокруг игрока до заполнения стака. |

## 6. Мета-активности и эндгейм

* **Слот-машина (CarPot):**
  * Стоимость спина: $100.
  * Награды: множители денег (х0, х2, х5), временный буст скорости, либо уникальные коллекционные скины машин (золотые, хромированные).
* **Скрытые коллекционки:**
  * 10 золотых гаечных ключей, спрятанных в труднодоступных местах склада.
  * Награда: разблокировка уникальной сборной машинки игрока.
* **Финал игры:**
  * Расстановка всех машинок по каталогу.
  * Доставка финальной машинки директора («Boss Car») на стол в закрытый офис.

## 7. Технические требования и оптимизация

* **Физические слои (Collision Layers):**
  * Отдельный слой для машинок в куче (`LooseItems`).
  * Отключение физики (`isKinematic = true`) и смена слоя на `StaticPlaced` сразу после фиксации на полке для экономии процессорного времени PhysX.
* **LOD & Окклюзия:** Использование LOD-групп для Low-poly моделей и агрессивный Frustum Culling, чтобы исключить просадки FPS при взгляде на сотни заполненных полок.
* **Система сохранений:** Сериализация состояния полок (ID машинки в каждом слоте) в JSON + автоматический локальный бэкап при каждом закрытии стеллажа.
